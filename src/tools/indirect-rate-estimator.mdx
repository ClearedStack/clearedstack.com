## Overview & Role

The **Indirect Rate Estimator** (`indirect-rate-estimator`, CLIN `0001`: Pricing & cost accounting) is a standalone, MIT-licensed static browser utility generated by Moldloft using the deterministic `calculator` stack template. It takes a contractor's annual direct labor, indirect labor, and indirect cost pools (fringe, overhead, and G&A) and calculates the resulting indirect rates under selectable allocation base conventions.

Because indirect rates are meaningless without their allocation bases, the tool enforces explicit base selection and displays the exact numerator and denominator for every rate. It executes 100% in browser memory with zero backend servers, zero runtime AI, and zero outbound network requests.

## Governing Regulations & Sources

| Authority | Citation | Role in Tool |
| --- | --- | --- |
| **FAR Part 31** | FAR 31.201-2, 31.202, 31.203 | Defines cost allowability, direct costs, indirect cost pools, and consistent allocation bases. |
| **FAR 31.205 Cost Principles** | FAR 31.205-1, -3, -8, -14, -15, -20, -22, -51 | Lists expressly unallowable costs (advertising, bad debts, donations, entertainment, fines, interest, lobbying, alcohol) that must be excluded from every pool. |
| **FAR Subpart 42.7 & Clause 52.216-7** | FAR 42.703-1, 42.705, 52.216-7 | Governs fiscal-year indirect cost rate pools, provisional billing rates, and annual incurred cost submissions. |
| **Cost Accounting Standards (CAS)** | 48 CFR 9903.201-1, 9904.410 | Notes the small-business CAS exemption while referencing standard Total Cost Input (TCI) vs. Value-Added G&A base definitions. |
| **DCAA Manual 7641.90** | *Information for Contractors* | Standard reference for three-pool (Fringe, Overhead, G&A) and two-pool (Fringe, G&A) small-business rate structures. |

## Inputs, Calculation Logic & Outputs

### Inputs

| Field | Type | Constraints / Options | Default |
| --- | --- | --- | --- |
| **Direct Labor Dollars (`DL`)** | Currency (`$`) | `>= 0.00` | `600,000.00` |
| **Indirect Labor Dollars (`IL`)** | Currency (`$`) | `>= 0.00` | `100,000.00` |
| **Fringe Pool (`P_fringe`)** | Currency (`$`) | `>= 0.00` (allowable fringe costs only) | `210,000.00` |
| **Overhead Pool (`P_oh`)** | Currency (`$`) | `>= 0.00` (allowable overhead costs only) | `156,000.00` |
| **Overhead Base Convention** | Enum | `dl_plus_fringe` (direct labor + fringe on direct labor) or `dl_only` (direct labor alone) | `dl_plus_fringe` |
| **G&A Pool (`P_ga`)** | Currency (`$`) | `>= 0.00` (allowable G&A costs only) | `112,320.00` |
| **G&A Base Convention** | Enum | `total_cost_input` (all costs beneath G&A) or `value_added` (excludes subcontracts & direct materials/ODCs) | `total_cost_input` |
| **Subcontracts & Direct Materials / ODCs (`Sub_ODC`)** | Currency (`$`) | `>= 0.00` (included in G&A base under `total_cost_input`, excluded under `value_added`) | `0.00` |

### Calculation Logic

1. **Fringe Rate (`R_fringe`):**
   - `fringe_base = DL + IL`
   - `R_fringe = P_fringe / fringe_base` (expressed as `%`, `0.00%` if `fringe_base == 0`)
2. **Fringe Allocated to Direct Labor (`F_dl`):**
   - `F_dl = DL * R_fringe`
3. **Overhead Base (`B_oh`) & Overhead Rate (`R_oh`):**
   - If `dl_plus_fringe`: `B_oh = DL + F_dl`
   - If `dl_only`: `B_oh = DL`
   - `R_oh = P_oh / B_oh` (expressed as `%`, `0.00%` if `B_oh == 0`)
4. **G&A Base (`B_ga`) & G&A Rate (`R_ga`):**
   - If `total_cost_input`: `B_ga = DL + F_dl + P_oh + Sub_ODC`
   - If `value_added`: `B_ga = DL + F_dl + P_oh`
   - `R_ga = P_ga / B_ga` (expressed as `%`, `0.00%` if `B_ga == 0`)

### Outputs

- **Calculated Rates:** Fringe Rate (`%`), Overhead Rate (`%`), and G&A Rate (`%`) rounded to 2 decimal places (`XX.XX%`), with full-precision ratios shown in the formula breakdown.
- **Pool-and-Base Breakdown Table:** Shows each pool's numerator, exact denominator components, and resulting rate.
- **Unallowable Cost Reminder:** Checklist reminding users to segregate unallowable expenses (FAR 31.205) into separate general-ledger accounts before entering pool totals.
- **Handoff Summary:** Displays the three resulting rates formatted for direct entry into the [Wrap Rate Calculator](/tools/wrap-rate-calculator/).

## Worked Example & Verification

### Primary Fixture (from *Labor rates and wrap rates*)

- **Inputs:** `DL = $600,000`, `IL = $100,000`, `P_fringe = $210,000`, `P_oh = $156,000` (`dl_plus_fringe`), `P_ga = $112,320` (`total_cost_input`), `Sub_ODC = $0`.
- **Expected Output:**
  - **Fringe Rate:** `$210,000 / ($600,000 + $100,000) = $210,000 / $700,000` = **`30.00%`**
  - **Direct Labor with Fringe:** `$600,000 × 1.30` = `$780,000` (`F_dl = $180,000`)
  - **Overhead Rate:** `$156,000 / $780,000` = **`20.00%`**
  - **G&A Base (TCI):** `$600,000 + $180,000 + $156,000` = `$936,000`
  - **G&A Rate:** `$112,320 / $936,000` = **`12.00%`**

### Boundary & Convention Fixtures

- **Value-Added vs. TCI Check:** Adding `Sub_ODC = $100,000` with `P_ga = $112,320`:
  - Under `total_cost_input`: `B_ga = $1,036,000` → `R_ga = 10.84%`
  - Under `value_added`: `B_ga = $936,000` → `R_ga = 12.00%`
- **Zero Base Guard:** Entering `DL = 0` and `IL = 0` displays `0.00%` (or `N/A — zero base`) without `NaN` or runtime errors.
