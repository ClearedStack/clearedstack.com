## Overview & Role

`cs-09-monitor` is the continuous monitoring worker in the `cs-workers` namespace (`ownerRepo: cs-09-monitor`, version `v0.1.0-draft`). Replacing the original Stage 10 (Revisit), it watches federal regulatory feeds, `live` ClearedStack tools, external `linked` tools, and `parked` blockers for drift.

`cs-09-monitor` is a 100% deterministic Go service with zero AI at runtime. Rather than scraping pages blindly or patching tools directly, it uses lightweight HTTP ETags, structured XML/API feeds, and deterministic DOM diffs—and reopens affected `PA-XXXX` items in `hub-queue-api` so the main pipeline handles updates cleanly.

## Interfaces & State Transitions

`cs-09-monitor` pulls scheduled watch tasks from `hub-queue-api` over cluster-private HTTP using its Kubernetes ServiceAccount identity (`lease`, `heartbeat`, `complete`, `fail`, `needs_subtool`). It never touches `postgres` directly.

When a deterministic diff confirms a meaningful change, `cs-09-monitor` stages the finding in `/var/spool/cs` and requests a state transition through `hub-queue-api`:

| Current State | Reopened Target State | Priority Lane | Condition |
| --- | --- | --- | --- |
| `live` | `building` | `urgent` | Governing regulation shifted or live tool rule version drifted; preempts normal/backfill work for an updated release. |
| `live` | `retired` | `urgent` | Underlying statutory rule or clause was repealed or superseded. |
| `parked` | `observed` | `normal` | Previously named blocker (e.g., pending rule or missing public data) cleared on scheduled revisit. |
| `linked` | `observed` | `normal` | External free tool went offline, added a paywall, or introduced tracking scripts; returned for clean-room build decision. |

## Sub-Tools & Failure Modes

Each source type is implemented as a deterministic sub-tool under `tools/<case>/` inside the `cs-09-monitor` repository, paired with golden test fixtures:

| Sub-Tool | Target Monitored | Detection Method |
| --- | --- | --- |
| `federal-register` | Federal Register notices and rulemakings | Scheduled XML and API diffs for FAR, DFARS, and small-business rule updates. |
| `ecfr` | Electronic Code of Federal Regulations | HTTP ETag and XML diffs tracking modified clauses, thresholds, and effective dates. |
| `nist-csrc` | NIST Computer Security Resource Center | Scheduled feed and DOM diffs for cybersecurity standards such as SP 800-171. |
| `linked-tool-watch` | External tools marked `linked` in the catalog | Periodic HTTP and DOM checks for dead links, new paywalls, or added tracking scripts. |
| `live-catalog` | ClearedStack tools published as `live` | Scheduled health and rule-version checks against active catalog entries. |

| Error Code | Trigger | Pipeline Behavior |
| --- | --- | --- |
| `E_TIMEOUT` | Upstream government feed or external linked site fails to respond in time | Item stays safe in queue for retry; repeated timeouts are deduplicated by `cs-10-notify`. |
| `E_PARSE` | Corrupt XML/JSON feed or broken HTTP response | Refuses to guess; logs sanitized failure and halts that check cleanly. |
| `E_NEEDS_SUBTOOL` | Upstream feed or DOM layout changes to an unrecognized structure | Fails closed, pauses item in `needs_subtool`, and triggers `cs-10-notify` to open a task; auto-replays after `cs-store` deploys the new watcher. |

## Security & Clean-Room Boundaries

- **Restricted network egress:** Default-deny network policies permit `cs-09-monitor` to call `hub-queue-api` and approved public regulatory/catalog targets only; `postgres`, `cs-git`, and `cs-registry` are unreachable.
- **Unprivileged pod posture:** Runs as non-root with dropped Linux capabilities, no privilege escalation, and a read-only root filesystem (apart from `/var/spool/cs`).
- **Clean-room separation:** `cs-09-monitor` only inspects public regulatory feeds and catalog metadata; it never injects raw external HTML into `cs-06-build` payloads (`hub-queue-api` rejects any such attempt).
- **Sanitized status:** Internal cluster details are stripped by `cs-store` before any `E_TIMEOUT`, `E_PARSE`, or `E_NEEDS_SUBTOOL` alert is surfaced publicly.
