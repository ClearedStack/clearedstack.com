## Overview & Role

The **Wrap Rate Calculator** (`wrap-rate-calculator`, CLIN `0001`: Pricing & cost accounting) is a standalone, MIT-licensed static browser utility generated by `cs-06-build` using the deterministic `calculator` stack template. It converts a direct labor wage or annual salary into a fully burdened hourly billing rate and computes both the cost wrap rate (without fee) and the billing wrap rate (with fee).

The tool runs 100% in browser memory with zero backend services, zero runtime AI, and zero network calls after initial page load. It is designed for small federal contractors preparing time-and-materials (T&M), labor-hour, cost-reimbursement, or fixed-price labor estimates who need transparent, auditable step-by-step math.

## Inputs, Calculation Logic & Outputs

### Inputs

| Field | Type | Constraints / Options | Default |
| --- | --- | --- | --- |
| **Pay Input Mode** | Enum | `hourly_wage` or `annual_salary` | `hourly_wage` |
| **Base Pay** | Number (`$`) | `>= 0.00` | `60.00` |
| **Annual Divisor Hours** | Number (`hrs`) | `> 0` (used when `annual_salary` is selected; `2080` if leave is in fringe, `1880`–`1920` if leave is excluded from fringe) | `2080` |
| **Fringe Rate** | Percentage (`%`) | `>= 0.00` | `30.00` |
| **Overhead Rate** | Percentage (`%`) | `>= 0.00` | `20.00` |
| **Overhead Base Convention** | Enum | `dl_plus_fringe` (direct labor + fringe) or `dl_only` (direct labor wage alone) | `dl_plus_fringe` |
| **G&A Rate** | Percentage (`%`) | `>= 0.00` | `12.00` |
| **G&A Base Convention** | Enum | `total_cost_input` (wage + fringe + overhead) or `value_added` (selectable exclusion note) | `total_cost_input` |
| **Fee / Profit Rate** | Percentage (`%`) | `>= 0.00` | `8.00` |

### Calculation Logic

1. **Base Hourly Wage (`W`):**
   - If `hourly_wage`: `W = base_pay`
   - If `annual_salary`: `W = annual_salary / divisor_hours`
2. **Fringe (`F`):**
   - `fringe_dollars = W * (fringe_rate / 100)`
   - `subtotal_with_fringe = W + fringe_dollars`
3. **Overhead (`OH`):**
   - If `dl_plus_fringe`: `oh_base = subtotal_with_fringe`
   - If `dl_only`: `oh_base = W`
   - `oh_dollars = oh_base * (oh_rate / 100)`
   - `subtotal_with_oh = subtotal_with_fringe + oh_dollars`
4. **General & Administrative (`G&A`):**
   - `ga_dollars = subtotal_with_oh * (ga_rate / 100)`
   - `total_cost = subtotal_with_oh + ga_dollars`
5. **Fee (`Fee`) & Fully Burdened Rate:**
   - `fee_dollars = total_cost * (fee_rate / 100)`
   - `burdened_rate_unrounded = total_cost + fee_dollars`
   - `burdened_rate = round_to_cent(burdened_rate_unrounded)`
6. **Wrap Multipliers:**
   - `wrap_rate_cost = total_cost / W` (when `W > 0`)
   - `wrap_rate_with_fee = burdened_rate_unrounded / W` (when `W > 0`)

### Outputs

- **Step-by-step build-up table:** Base wage, Fringe (`$` and running total), Overhead (`$` and running total), G&A (`$` and running total), Fee (`$` and running total).
- **Fully Burdened Hourly Rate:** Displayed rounded to the nearest cent (`$X.XX`) alongside unrounded precision for auditability.
- **Wrap Rate on Cost** and **Wrap Rate with Fee:** Displayed to 4 decimal places (`1.XXXX`).
- **Convention Warning Banner:** Explicitly states which Overhead and G&A base conventions were applied and warns against mixing leave-in-fringe with reduced divisor hours (double-counting leave).

## Clean-Room & 5-Condition QA Requirements

Before `cs-07-verify` promotes `wrap-rate-calculator` to `live`, the static bundle must pass all five platform conditions:

1. **Offline Execution:** Loads once and performs all calculations locally in browser memory with zero network calls and zero external CDN or font dependencies.
2. **Strict Content Security Policy:** Enforces `default-src 'self'; connect-src 'self'; form-action 'none'` so no rate data can leave the user's machine.
3. **Zero Tracking or Accounts:** No sign-in walls, analytics scripts, cookies, or beacons. Any optional `localStorage` persistence of draft inputs must be disclosed on the page with a one-click **Clear Data** control.
4. **Worked-Example Assertions & Synthetic Fixtures:** Automated test suite asserts exact outputs against hand-calculated synthetic fixtures and boundary cases (zero rates, zero wage guard, `dl_only` vs. `dl_plus_fringe` toggle, salary conversion). Real contractor rates and CUI are strictly forbidden.
5. **Citations, Scope Limits & MIT License:** Displays inline FAR Part 31 citations, explicitly states scope exclusions (does not determine cost allowability, audit readiness, or SCA wage-determination compliance), includes a non-advice disclaimer, and ships an `MIT` `LICENSE` file.

## Worked Example & Verification

### Primary Fixture (from *Labor rates and wrap rates*)

- **Inputs:** Hourly wage `$60.00` (or `$124,800 / 2,080 hrs`), Fringe `30%`, Overhead `20%` on `dl_plus_fringe`, G&A `12%` on `total_cost_input`, Fee `8%`.
- **Expected Step-by-Step Output:**
  - Base wage: `$60.00`
  - Fringe (`30%` of `$60.00`): `+$18.00` → Running total `$78.00`
  - Overhead (`20%` of `$78.00`): `+$15.60` → Running total `$93.60`
  - G&A (`12%` of `$93.60`): `+$11.23` (`$11.232`) → Running total `$104.83` (`$104.832`)
  - Fee (`8%` of `$104.832`): `+$8.39` (`$8.38656`) → Fully burdened rate **`$113.22`**
  - Wrap rate on cost: `1.30 × 1.20 × 1.12 = 1.7472`
  - Wrap rate with fee: `1.30 × 1.20 × 1.12 × 1.08 = 1.8870`

### Sanity Check & Boundary Fixtures

- **Round-Number Verification Fixture (from *Check a tool's answer*):** Wage `$50.00`, Fringe `30%`, Overhead `20%` (`dl_plus_fringe`), G&A `10%`, Fee `8%` → **`$92.66`** (`50.00 × 1.30 × 1.20 × 1.10 × 1.08 = 92.664`).
- **`dl_only` Convention Check:** With `$60.00` wage, `30%` fringe, `20%` overhead on `dl_only` (`+$12.00` instead of `+$15.60`), subtotal before G&A must equal `$90.00`.
- **Zero Wage Edge Case:** `W = 0.00` returns `$0.00` burdened rate and `N/A` for wrap multipliers (no division-by-zero `NaN` or `Infinity`).
