A tool gives you a worked answer quickly. You are still the one who signs the proposal, so treat every result as a draft until you have checked it.

## Find the source

Each listed tool has to say which regulation, standard or guide it is built on. Look for that reference in the tool or in its repository’s README.

## Compare it with the current text

Open the source and read the part the tool relies on. Pay attention to dates. Regulations are revised, and some figures change on a schedule. The Prompt Payment Act interest rate, for example, is reset every six months.

If the tool and the current text disagree, the text wins.

## Follow the solicitation

A solicitation can set its own rules for format, page counts, pricing structure and more. When it says something different from a tool’s default, follow the solicitation and adjust the tool’s inputs to match.

## Read the code

Every tool is open source. The **Source** link next to a tool in the [catalog](/tools/) opens its repository, where the formulas and data are there to read.

## Report a mistake

If a tool gets something wrong, say so. Email [contact@clearedstack.com](mailto:contact@clearedstack.com) or open an issue in the tool’s repository, and include the section of the regulation that shows the correct answer. A wrong result is the most useful thing you can report.

## What the tools are not

They are not legal, accounting or compliance advice. For a decision that carries real risk, such as an indirect rate structure or a compliance attestation, talk to a qualified professional.
